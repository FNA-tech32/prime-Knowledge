# Prime Knowledge

Prime Knowledge is a one-page website for a school coaching centre. It covers classes 1 to 10, a free demo offer, class videos, and ways to get in touch.

Open `index.html` in a browser to view the site. There is no build step.

## Page

The page is a single file, `index.html`.

| Section | What it shows |
| --- | --- |
| Header | The Prime Knowledge name |
| Offer | A notice for 3 days of free demo classes |
| Classes | Classes 1st to 10th. All subjects for 1st to 8th. Mathematics, Science, and Urdu for 9th and 10th |
| Welcome | The line “ज्ञान है तो पहचान है” and an invitation to join |
| Videos | Two class clips. Click a video to play it, and click again to pause |
| Footer | Instagram, phone, email, an alternative contact, and the centre address |
